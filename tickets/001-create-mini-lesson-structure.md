# 001 - Create mini-lesson structure

## Goal

Create a separate mini-lesson content area with a reusable v1 schema for staged learning.

## Scope

- Add `mini-lessons/README.md` documenting schema and naming.
- Add `mini-lessons/index.md` as a pack entrypoint.
- Reserve `mini-lessons/packs/` for lesson packs.

## Acceptance Criteria

- Separate mini-lesson directory exists.
- Schema includes lesson metadata, progression rules, and 3 stage arrays.
- Authoring guidance is documented.

## Dependencies

- None

## Notes

Completed as part of initial scaffold.
